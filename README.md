# SWYNEX – Exploratory Data Analysis of Indian Rainfall

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of historical Indian rainfall data from 1901 to 2017. Python was used to explore rainfall patterns, compare rainfall across subdivisions, and identify seasonal variations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains historical rainfall records for Indian subdivisions, including monthly, annual, and seasonal rainfall measurements from 1901 to 2017.

## Project Tasks
- Explored and analyzed the cleaned rainfall dataset.
- Examined monthly and seasonal rainfall patterns.
- Compared average annual rainfall across subdivisions.
- Analyzed annual rainfall statistics and variations.
- Used charts and visualizations to identify patterns.
- Examined potential outliers in annual rainfall.

## Key Insights
1. July recorded the highest average monthly rainfall in the analysis.
2. Rainfall varied considerably across Indian subdivisions.
3. Arunachal Pradesh had the highest average annual rainfall among the subdivisions analyzed.
4. West Rajasthan had the lowest average annual rainfall among the subdivisions analyzed.
5. The analysis highlighted seasonal rainfall patterns and unusually high annual rainfall observations.

## Project Files
- `Weather_Data_Cleaning_EDA.ipynb` – Python notebook containing analysis and visualizations.
- `cleaned_weather_data.csv` – Cleaned rainfall dataset.

## Conclusion
This project demonstrates the use of Python for exploratory data analysis, data visualization, and identifying patterns in historical rainfall data.
